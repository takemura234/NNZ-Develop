# NNZモデルチェンジ 9/23打合せ結果

## 打合せ概要

2026年9月23日、廣田GM、淵田、中村、磯貝の4名にて、NNZ（アルネオ）モデルチェンジについて打合せを実施した。

今回の打合せでは、単純に現行NNZを新型へ置き換えるだけではなく、**既存商品の統合・整理を含めた次期商品構成**を意識して検討を進める方向が確認された。

## 1. 商品構成・モデル統合について

現行の各商品について、単純な後継機種への置き換えではなく、今後の商品体系を整理したうえでモデルチェンジを検討する。

-   会社全体の商品構成を統合するイメージで検討
-   各販売店で現在販売している本体・仕様を整理する
-   各商品の販売実績を確認し、今後残すべき仕様・統合できる仕様を検討する
-   現行機種をそのまま新型へ置き換えるのではなく、仕様統合や改造対応を含めて商品体系を整理する
-   4t仕様についても、現行商品を残す方向を含めて検討する

既存商品をすべて新機種へ統合するのではなく、販売実績や市場ニーズを確認したうえで、標準機種として残すもの、統合するもの、改造対応とするものを整理する。

## 2. 4t仕様・スペースリフトについて

スペースリフト（レグルス）等の4t仕様についても、今後の商品体系の中で残すかどうかを検討する。

現時点では4t仕様を残す方向を含めて検討し、必要に応じて他機種との仕様統合や改造対応によって整理する考え方が出された。

## 3. モデルチェンジの設計方針

モデルチェンジでは、単純な部品変更だけではなく、実際の商品として成立させるための設計を進める。

-   モータ変更等による仕様変更の可能性を検討
-   変更した仕様が実際の商品として成立するか確認
-   既存部品との共通化・流用可能性を確認
-   商品構成を整理したうえで、実現可能な構造・仕様へ落とし込む

## 4. 2Way仕様の課題

2Wayタイプについて、現行案をベースに以下の課題・要求事項が挙げられた。

-   スライド量をさらに伸ばしたい
-   受台・アーム周辺の構造を見直したい
-   よりフラットな受台形状を検討したい
-   実機として成立させるための具体的な設計検討が必要

ホワイトボード上でも受台・アーム周辺の構造について具体的なスケッチを行い、実現可能な構造を検討した。

## 5. 今後の検討事項

今後は、以下の順番で検討を進める。

1.  現行アルネオ関連機種の洗い出し
2.  各販売店で販売している仕様・機種の整理
3.  各機種の販売実績・販売数量の確認
4.  「残す・統合する・改造対応とする」機種の整理
5.  次期NNZの標準仕様を決定
6.  2Way仕様を中心とした構造・受台の具体設計
7.  モータ等の主要構成部品変更の検討
8.  強度・性能・実機成立性の確認

## 6. 今回の打合せを踏まえた開発の考え方

今回の打合せにより、NNZモデルチェンジは、

**「現行NNZのスペックアップ」**

から、

**「既存アルネオ商品の販売実績・仕様を整理し、商品体系を統合したうえで次期NNZを設計する」**

という視点を持って進める必要がある。

そのため、今後の設計検討に先立ち、各販売店での販売機種・仕様と販売実績を整理し、どの仕様を次期NNZへ取り込むべきかを明確にする。
